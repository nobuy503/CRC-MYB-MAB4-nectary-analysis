# Analysis scripts

The manuscript analysis code is organized by main figure:

- `figure1_snrnaseq/`: public flower and silique snRNA-seq analyses for
  Fig. 1 and associated supplementary analyses.
- `figure2_slideseq/`: Slide-seq spatial transcriptomics analyses for
  Fig. 2 and Supplementary Fig. 3.

Each figure folder contains its own README. Finalized panel-specific scripts
are stored under `final/`; original or exploratory workflows are stored under
`source/` or `exploratory/`.
