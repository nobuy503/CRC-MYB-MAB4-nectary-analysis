# CRC–MYB–MAB4 nectary analysis

Analysis code associated with the study of CRC–MYB–MAB4 regulation during *Arabidopsis thaliana* nectary development.

## Repository status

This repository is currently being prepared for publication. Analysis scripts, software versions, required input descriptions and reproduction instructions will be added before the repository is made public and archived.

## Planned contents

- `scripts/`: R scripts used for snRNA-seq, Slide-seq, pseudotime and figure analyses
- `data/`: instructions for obtaining deposited and publicly available input data
- `results/`: descriptions of the outputs generated by each script

## Data availability

The sequencing datasets generated in this study are deposited in the DNA Data Bank of Japan under BioProject accession numbers PRJDB20796 and PRJDB35443. The public single-nucleus RNA-seq dataset analyzed in the study is available from NCBI GEO under accession number GSE226097.

Large sequencing files and processed expression objects are not stored in this repository.
